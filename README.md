# EVERGUARD

Панель показывает последние показания DHT22, MQ-2 и MQ-135 из Supabase. ESP32 отправляет их по Wi-Fi, а страница запрашивает свежую запись каждые пять секунд.

## Как проверить изменения

1. Сделайте Fork этого репозитория и откройте свою копию в редакторе.
2. Меняйте разметку и стили в index.html, загрузку показаний в dashboard.js.
3. Для своей онлайн-версии включите Settings → Pages → Deploy from a branch → main → / (root).
4. Отправляйте изменения в main своей копии и проверяйте сайт по адресу из Settings → Pages.
5. Когда изменения готовы, откройте Pull Request в исходный репозиторий.

В браузере используется публичный ключ Supabase. Пароль Wi-Fi, токен отправки с ESP32 и серверные ключи храните вне репозитория.
